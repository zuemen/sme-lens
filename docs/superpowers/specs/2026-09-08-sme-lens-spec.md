# 企鏡 SME Lens 產品規格

**版本：** 1.0（2026-09-08）
**用途：** 2026 年臺灣中小企業銀行校園金融科技創意挑戰賽參賽作品
**Repo：** https://github.com/zuemen/sme-lens

---

## 1. 產品定位

**一句話：** 把銀行既有的轉帳流水、票據與企業登記關係變成一張「企業關係圖」，讓沒有漂亮財報的中小企業也能用**交易網絡**當信用證據；並讓每一個 AI 判斷都附帶**可稽核的結構證據**，而不是黑箱分數。

**產品名：** 企鏡 SME Lens
**核心主張：** 銀行不缺分數，缺的是**看得見的理由**。

**選題依據（2025 年得獎解剖）：** 冠軍 CrossFin Bridge（AI 授信風控＋穩定幣結算）、亞軍 ChainGuard（AI 雙引擎＋區塊鏈防偽・供應鏈金融）、季軍 柯基風控（企業自證＋外部驗證＋行員訪查）——**前三名全是企金／授信題**；而 GNN 防詐題（清大 BankGraph AI）只拿到第四的最佳潛力獎。故本案主軸必須是企金授信，防詐為副標籤。

## 3. 系統範圍

### 3.1 三個核心應用（授信全生命週期）

| 時點 | 痛點 | SME Lens 解法 |
|---|---|---|
| **貸前**：集團歸戶 | 關係人／集團授信歸戶靠客戶自行填報與行員人工查核，隱性關聯（共用董監事、交叉持股、共用登記地址）查不出來，導致集團曝險超限 | 以公司—自然人二部圖投影出公司關聯圖，Louvain 社群偵測揭露「登記上無關、實質同一集團」的隱性群組 |
| **貸中**：無財報授信 | 中小企業財報粗糙、擔保品不足，銀行僅能倚賴聯徵與擔保品，好公司借不到錢 | 以交易網絡結構產生**網絡信用分**：中心性位置、交易對手多樣性、金流穩定度，補財報之不足 |
| **貸後**：早期預警 | 貸後管理倚賴季報與行員訪查，上下游出事才知道，通常已來不及 | 圖上傳染擴散 + 企金風險圖樣（循環交易、空殼中介、買方集中）產生關注名單 |

### 3.2 防詐分支（第二情境標籤）

同一引擎換一組圖樣，偵測企業戶淪為金流水房：人頭公司集中開戶、資金快進快出、多對一歸集。沿用既有 `fan_in` / `fan_out` / `peeling_chain` / `gather_scatter` 圖樣與 STR（可疑交易報告）草稿生成。

### 3.3 雙引擎架構

```
引擎 A：看得見的關係 → SNA + GNN 圖風控        （本規格範圍）
引擎 B：信得過的資料 → 可驗證憑證 + 選擇性揭露  （後續計畫，源自 evidence-at-source）
         ↓
輸出：可解釋授信意見書
（結構證據 + 中文敘事 + 建議，行員可覆核、可寫入徵信報告、可對監理交代）
```

## 4. 技術基礎

核心圖引擎衍生自同作者的 **ChainLens**（MIT 授權），已在虛擬資產詐騙金流場域驗證：89 項 pytest、34 項 vitest、3 項 Playwright 測試全綠。

**直接沿用（不修改）：** `sna/metrics.py`（degree／PageRank／k-core／betweenness）、`sna/community.py`（Louvain）、`models/gcn.py`、`models/sage.py`、`models/train.py`
**小幅擴充：** `api/serialize.py`（`graph_to_json` 新增選配角色對照表參數）
**保留不動（防詐分支）：** `explain/evidence.py`、`explain/screening.py`、`sna/motifs.py`
**新增：** 企金風險圖樣、集團歸戶模組、授信意見書產生器、中小企業供應鏈情境圖、台灣企業關係圖建構器

**決策：企金語意獨立成 `smelens/credit/` 子套件，而非改寫 `explain/evidence.py`。** `evidence.py` 是 89 項既有測試的基礎，改動其評分權重會造成大量回歸；獨立子套件可複用其 `PipelineResult` 型別與百分位處理慣例，同時讓防詐分支與企金分支各自演進。

## 7. 非目標（明確排除）

- **不做**槓桿衍生品、鏈上永續合約、任何加密資產交易功能（法規紅線，且與賽事評審取向相斥）
- **不主打**穩定幣跨境結算（2025 冠軍已做過，避免撞題）
- **不做**供應鏈區塊鏈防偽（2025 亞軍已做過）
- 本計畫**不含**前端改造與真實開放資料接入（分屬計畫 2、3）

## 8. 驗收標準

1. `POST /credit` 對中小企業供應鏈情境圖中的任一公司，回傳含網絡信用分、關注分數、結構證據與中文授信敘事的授信意見書
2. `POST /group` 回傳隱性集團歸戶結果與集團曝險
3. 三個企金風險圖樣（循環交易、空殼中介、買方集中）各有獨立測試並全綠
4. 既有 89 項 ChainLens 測試在改名後仍全綠（不得因重構而回歸）
5. GitHub Actions CI 綠燈
